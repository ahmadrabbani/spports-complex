## Walkthrough

1. Open Members to create a synthetic applicant with category, complex, membership number, CNIC, phone and address, or reuse SYNTHETIC-JT-001.
2. Open SAP Challans → Generate challan. Search SYNTHETIC-JT-001 and select the member.
3. Select Johar Town center 3; choose Monthly Fee and enter 100. Preview should show PKR 100, cost 0021010003, profit 002101003 and REACON 260108.
4. Generate the mock challan. Choose Run Mock Payment, select delayed and Run simulation.
5. Open History / Response. Pending must leave the challan unpaid. Select Confirm delayed mock payment.
6. Reopen History / Response → MOCK Receipt. The challan should be paid and the receipt clearly marked TEST MODE.
7. Use fresh challans for failed, cancelled, timeout, amount mismatch and invalid transaction scenarios. These must not settle the challan.

